

# 🧮 C++ Simple CLI Calculator
https://imsoroush.ir/computer/Other_computer/cpp-calculatorhttps://imsoroush.ir/computer/Other_computer/cpp-calculator
یک ماشین حساب ساده اما هوشمند که در ترمینال (CLI) اجرا می‌شود. این پروژه با زبان C++ نوشته شده و برای تمرین مدیریت خطا (Error Handling) و ساختارهای کنترلی (Loops & Switch) طراحی شده است.

## ✨ ویژگی‌ها

- 🟢 پشتیبانی از چهار عمل اصلی (`+`, `-`, `*`, `/`)
- 🟢 پشتیبانی از اعداد اعشاری (Double)
- 🟢 مدیریت خطاهای ورودی (مثلاً اگر کاربر به جای عدد حرف بزند، برنامه کرش نمی‌کند)
- 🟢 جلوگیری از خطای تقسیم بر صفر
- 🟢 اجرای مداوم در یک حلقه تا زمانی که کاربر بخواهد خارج شود

---

## 🚀 نحوه کامپایل و اجرا

برای اجرای این برنامه نیاز به کامپایلر C++ (مثل `g++`) دارید.

1. کلون کردن مخزن:
```bash
git clone https://github.com/USERNAME/cpp-calculator.git
cd cpp-calculator
```

2. کامپایل برنامه:
```bash
g++ calculator.cpp -o calculator
```

3. اجرای برنامه:
```bash
./calculator
```
